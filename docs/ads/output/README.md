# Gudel-Schärfdienst-Reel

Das fertige Hochformat-Reel liegt in diesem Ordner:

- `gudel-schaerfdienst-reel.mp4` – 1080 × 1920 Pixel, 30 fps, H.264-Video mit AAC-Ton, 14,4 Sekunden
- `gudel-schaerfdienst-reel-cover.jpg` – Cover aus Sekunde 1 des fertigen Reels

## Inhalt

Das Reel nutzt das von Jan Bernd Gudel am 10. September 2026 bereitgestellte Werkstattvideo `assets/jan-bernd-cnc-saegeblatt-hochkant.mp4`. Es wurde auf 1080 × 1920 Pixel skaliert und mit den Kampagnenaussagen „Wir holen ab“, „Wir schärfen“, „Wir bringen zurück“ sowie dem Aufruf „Abholung anfragen“ versehen. Das Original-Audiosignal bleibt erhalten. Es wurden keine generierten Bilder oder fremden Stockaufnahmen verwendet.
